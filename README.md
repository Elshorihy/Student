# OmniTrack Student

React + Vite student dashboard prepared for deployment on Cloudflare Pages.

## Cloudflare Pages
- Framework: Vite
- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main`

## Important
The current version is a frontend prototype. State is held in React memory, so persistent accounts/data and real device-level app blocking require a backend/native component later.
